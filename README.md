> Own Your Identity

Identity Bridge is a **privacy-preserving** digital identity protocol on StarkNet L2 that enables users to _prove verified attributes_ using zero-knowledge proofs without exposing personal data. Built with zkBridge for cross-chain verification, zkVerify for proof validation, and optional Zcash for private notifications, the protocol keeps credentials in user-controlled wallets while _anchoring only cryptographic commitments_ on-chain. Powered by the **$SOVR token**, Identity Bridge provides seamless Web2-to-Web3 credential bridging with maximum privacy and minimal friction.
